## Dashboard File

The main Power BI file is:

`Apparel_Textiles_Interactive_Dashboard.pbix`

The dashboard contains:

- Total Products
- Total Brands
- Average Product Price
- Highest Product Price
- Lowest Product Price
- Total Colors
- Product Count by Brand
- Product Distribution by Gender
- Average Price by Brand
- Interactive slicers

## Purpose

The Power BI dashboard provides an interactive view of the apparel product catalog and helps users explore business information through KPIs, charts, and filters.
