# Week 2 — EDA Notebook

## Overview

This folder contains the Python/Google Colab notebook used to perform Exploratory Data Analysis (EDA) on the cleaned apparel and fashion dataset prepared during Week 1.

## Analysis Performed

The notebook includes:

- Loading the cleaned dataset
- Inspecting the dataset structure
- Checking rows and columns
- Analyzing product distribution
- Brand-wise product analysis
- Gender-wise product analysis
- Price analysis
- Color analysis
- Creating charts and visualizations
- Identifying business insights

## Main Analysis

### Product Analysis
Analyzed the overall product catalog and product distribution.

### Brand Analysis
Compared brands based on the number of products available.

### Gender Analysis
Examined product distribution across available gender categories.

### Price Analysis
Calculated and analyzed:

- Minimum price
- Maximum price
- Average price
- Price distribution

### Color Analysis
Identified the most frequently occurring primary colors.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab / Jupyter Notebook

## Notebook

The main notebook contains the complete Python code and analysis performed during Week 2.

**File:** `Apparel_Textiles_Data_Cleaning.ipynb`

## Output

The notebook generated charts that are stored separately in the `charts/` folder.

The results were used to prepare the **Week 2 EDA Report** and support later dashboard and business analysis.
