# Week 1 — Raw Data

## Overview

This folder contains the original publicly available datasets collected for the Apparel & Textiles Data Analytics project.

The raw datasets were used as the starting point for the data cleaning and preparation process. No major transformations were applied to the original files before analysis.

## Dataset 1 — Fashion Products Dataset

This dataset contains product-level information about fashion and apparel products.

### Main Columns

- ProductID
- ProductName
- ProductBrand
- Gender
- Price (INR)
- NumImages
- Description
- PrimaryColor

### Purpose

This dataset was used to analyze:

- Product portfolios
- Brands
- Gender categories
- Product prices
- Primary colors
- Product descriptions

## Dataset 2 — Dress Sales / Fashion Attributes Dataset

The second dataset contains additional apparel and fashion product attributes.

### Main Columns

- Style
- Price
- Rating
- Size
- Season
- NeckLine
- SleeveLength
- WaistLine
- Material
- FabricType
- Decoration
- PatternType
- Recommendation

### Purpose

This dataset provides additional information about fashion characteristics, product attributes, and recommendations.

## Data Source

The datasets were obtained from publicly available sources and were used for educational and internship project purposes.

## Data Processing

The original datasets were retained separately as raw data. Data cleaning, transformation, missing-value handling, standardization, and integration were performed in later stages of the project.

## Important Note

The raw data should not be modified directly. Cleaned and transformed versions are stored separately to maintain a clear distinction between the original source data and processed data.
