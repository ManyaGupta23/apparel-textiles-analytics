# Mapping

This folder contains the mapping tables created during Week 3 to standardize categorical values.

## Brand Category Mapping

The mapping converts individual product brands into broader business categories.

Example:

| ProductBrand | BrandCategory |
|---|---|
| SPYKAR | Fashion |
| Parx | Fashion |
| SHOWOFF | Fashion |
| Kenneth Cole | Luxury |
| Police | Accessories |
| Vishudh | Ethnic Wear |
| Homesake | Home Decor |

## Purpose

The mapping helps convert raw categorical information into standardized business categories for analysis and reporting.

## Files

Mapping files such as CSV or Excel files are stored in this folder.
